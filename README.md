# Sistema de Gestión - Restaurante-Bar

Proyecto desarrollado por Nahiara Vazques.

Este es un sistema que hice para la gestión de un restaurante / bar. La idea es poder llevar el control de mesas, pedidos, productos y facturación desde un mismo lugar.

Funciones principales:

- Control de mesas y comandas.
- Carga y administración de productos con stock.
- Registro de pedidos con estados.
- Sistema de facturación simple.
- Panel de administrador para ver todo el movimiento.

Tecnologias usadas:
Java, Spring Boot, MySQL, HTML, CSS, JavaScript.
